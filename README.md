# dashboard-for-DV-course
Dashboard to enable users to explore patterns, trends, anomalies, and business opportunities through interactive visual analytics.
The dataset get from https://www.kaggle.com/datasets/yoongsin/shopee-sample-data

# To run the code
Ensure all libraries needed is downloaded and dataset is download in csv file type
Check the code line 18, is the file path and name match. If not, edit it
Run "streamlit run app.py" in the terminal or command prompt
